# ShopFlow-ecommerce-data-analysis

🎯 Cel projektu:

Celem projektu była analiza danych sprzedażowych sklepu internetowego ShopFlow oraz przygotowanie danych do wiarygodnej analizy biznesowej. Projekt obejmował identyfikację i naprawę problemów jakości danych, a następnie analizę sprzedaży, klientów, produktów, sezonowości oraz stanów magazynowych przy użyciu SQL, PostgreSQL i Excela.

🗂️ Dane:

Źródło: symulowane dane sklepu internetowego ShopFlow
Liczba rekordów: ok. 85 000 rekordów w 5 powiązanych tabelach
Zakres: klienci, produkty, zamówienia, pozycje zamówień oraz stany magazynowe z 24 miesięcy działalności
Format: relacyjna baza danych SQL / PostgreSQL
 
🔧 Narzędzia i technologie:

SQL: PostgreSQL – czyszczenie, transformacja i analiza danych
DBeaver: praca z bazą danych i wykonywanie zapytań SQL
Excel: dodatkowa analiza i prezentacja wyników
Copilot: wsparcie przy tworzeniu i optymalizacji zapytań SQL

📝 Proces analizy:

Przygotowanie danych – identyfikacja i usunięcie duplikatów, braków danych, niespójnych formatów, wartości odstających oraz błędnych kluczy obcych. Szczegółowy proces czyszczenia danych został przedstawiony tutaj ....
Eksploracja danych – analiza struktury danych, sprzedaży, klientów, produktów i sezonowości.
Analiza właściwa – analiza wyników sprzedażowych, zachowań klientów, kategorii produktowych oraz stanów magazynowych przy użyciu SQL.
Wizualizacja wyników – podsumowanie i prezentacja kluczowych wyników w Excelu.
Wnioski biznesowe – wskazanie najważniejszych trendów, problemów i obszarów wspierających decyzje biznesowe.
